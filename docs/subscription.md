# 订阅与规则

安装完成后脚本会打印订阅地址。粘进 FlClash 的「订阅」即可使用。

## 随时查看订阅地址

不需要登录网页或找记录，一条命令：

```bash
xray-admin --sub
```

输出示例：

```text
订阅地址（复制到 FlClash 订阅栏）：
http://203.0.113.10:34441/cgi-bin/0123456789abcdef0123456789abcdef

规则文件：/etc/xray-sub/rules.yaml
通用规则：79 条
私有规则：4 条
订阅服务：运行中
```

## 换电脑 / 换 VPS 怎么办

这是两件不同的事，分开看。

### 只换电脑（VPS 不变）

新电脑上**什么都不用重建**。执行 `xray-admin --sub` 拿到订阅地址，粘进新电脑的 FlClash 即可。

规则都在 VPS 上，跟着订阅一起下发，新电脑自动拿到。

想留个备份，可以在菜单里选 **10 导出订阅信息到文件**，会生成 `/root/xray-subscription.txt`，里面包含订阅地址和你的私有规则，下载到电脑保存即可。

### 换 VPS（服务器也换）

私有规则**不会**随脚本走，因为它不在仓库里。需要手动迁移：

1. **换之前**，在旧服务器执行 `xray-admin`，选 10 导出订阅信息
2. 把 `/root/xray-subscription.txt` 下载到自己电脑
3. 在新服务器上跑一键安装
4. 执行 `xray-admin` 选 6 编辑私有规则，把文件里「私有规则」那一段原样粘回去
5. 执行 `xray-sub`，新订阅地址生效

注意：换 VPS 后订阅地址会变（令牌是新的），新电脑和旧电脑都要重新导入。

## 流量额度会显示吗

会。Clash 系客户端（含 FlClash）通过 HTTP 响应头 `Subscription-Userinfo` 读取额度，我在订阅里加入了这项支持。

设置方式：`xray-admin` 选 **9 设置流量额度**，依次填：

```text
已上传字节数 [0]
已下载字节数 [0]
总流量字节数（0=不限，100GB=107374182400） [0]
到期时间（Unix 时间戳，0=长期有效） [0]
```

然后 FlClash 下拉刷新订阅，卡片上就会显示用量和剩余。

### 关于"一个月 100GB 还是无限"

这取决于你 VPS 供应商给的实际套餐。**脚本不会自动知道**，因为：

- 供应商的流量统计在宿主机，容器内看不到
- 没有 API 可查

所以两个选择：

| 情况 | 怎么填 |
|---|---|
| 供应商给你 200GB/月，你只想显示自己设定的目标 | `total` 填你要的上限，例如 100GB |
| 供应商不限流量 | `total` 填 0，客户端显示"不限制" |
| 想看到真实已用量 | 客户端不会自动同步，需手动更新 `download` 值，或用供应商后台看 |

**最重要的是**：这里的数字只是给客户端显示用，**不会真的限速或断网**，因为脚本不统计数据。真要限额，得在 Xray 层做流量统计，那会增加内存开销，这台 128 MB 的机器不适合。

建议填法（仅供参考）：`total=0`，表示不限制，避免显示一个不准确的"已用/总量"。

## 订阅不能和代理共用端口

订阅需要独立端口。共用只有两种做法，都不划算：

1. 改 REALITY fallback，让未认证流量返回订阅页 → 探测者直接看到你的订阅页，伪装失效
2. 前置 nginx 做 SNI 分流 → 128 MB 机器上多一个常驻进程

所以订阅固定监听实例内 `127.0.0.1:2096`，公网端口由你在平台映射。安装时会问一次，之后可用 `xray-admin` 选 8 修改。

## 私有规则

| 文件 | 内容 | 进仓库 |
|---|---|---|
| `/etc/xray-sub/rules.yaml` | 通用规则 | 是 |
| `/etc/xray-sub/rules.local.yaml` | 你的私有规则 | **否** |

合并顺序：私有规则 → 通用规则。私有规则优先，不会被 `MATCH,PROXY` 抢走。

写错格式时 `xray-sub` 拒绝生成，**旧订阅保持不变**。

## 安全说明

订阅地址里的令牌等同密码。任何拿到它的人都能：

- 获取你的节点参数（UUID、公钥）
- 用你的节点上网

但**拿不到服务端私钥**（测试有断言）。

所以：

- 不要发到群里或公开仓库
- 换 VPS 后旧令牌随旧服务器一起消失
- 怀疑泄露时，删除 `/etc/xray-sub/token` 重装即可换新令牌
