# 部署细节

本文件只记录通用说明和已做过的验证，不含任何具体实例的 IP、端口或目标站。

## 脚本做的事

`one-click.sh` 会按顺序执行：

1. 检查 root 权限、Debian、systemd、amd64。
2. 收集七项参数：公网地址、代理公网/内部端口、REALITY 目标、serverName、订阅公网/内部端口。重复安装时已保存值作为默认值显示，但仍逐项询问。
3. 安装缺失的工具依赖（`ca-certificates curl openssl unzip jq iproute2 procps busybox nano`）。
4. 校验目标站：解析结果必须是公网地址（拒绝私网、回环、链路本地、CGNAT、文档/基准测试网段和 IPv6 本地地址）；证书有效、TLS 1.3、ALPN h2 必须通过。HTTP 状态只作参考，不作为安装门槛。
5. 下载固定版本 Xray，校验 SHA256。
6. 生成配置，用真实 Xray 做 `-test` 校验。
7. 创建 `xray` 系统用户，安装独立 systemd 服务并启动。
8. 用 `xray-admin --export` 导出客户端节点到 `/root/xray-client/node.json`（一键入口会自动执行；单独运行安装器时手动执行）。

不会修改端口映射、防火墙、APT 源、内核参数或系统 DNS。

## 端口怎么填

云平台的端口转发通常有两列：

```text
外部端口（客户端连这个）  →  内部端口（实例内程序监听这个）
```

脚本会分别询问：

- **公网 TCP 端口**：填外部端口。
- **内部 TCP 端口**：填内部端口。

没有 NAT 的 VPS 两个值相同，通常都是 443。有 NAT 的容器/小机必须按平台实际映射填写，否则服务起来了也连不上。

## REALITY 目标怎么选

脚本预置 `www.microsoft.com:443` 只是让第一次安装有可用的起始值，不代表它是长期推荐目标，也不保证不被封。Xray 的运行日志可能对常见目标给出警告；目标站的可用性和封锁情况会随时间、地区和网络变化。

脚本每次安装都会**实时复验**：解析结果不能是私网/回环/CGNAT/IPv6 本地地址，证书、TLS 1.3、ALPN h2 必须通过。HTTP 状态只打印出来参考，不作为安装门槛。没有“实测长期可用”的承诺。

想换目标时，第 4 项填 `域名:443`，第 5 项填同一域名。不要用 Apple 系域名；脚本会直接拒绝这类目标。

## 密钥与重复安装

- 首次安装生成 UUID、X25519 密钥对和 shortId。
- 重复运行会读取已保存的状态，**不会更换密钥**；安装前会用真实 Xray 从私钥推导公钥并与保存值比对，不一致就停止，不会静默复用坏凭据。
- 想强制换密钥，需要先备份并删除 `/usr/local/etc/xray/client.json`，再重装；所有已导入客户端都会失效，需要重新导入新订阅。

## 回退

安装过程中任何一步失败，脚本会恢复旧的二进制、配置和服务单元，并尽量拉起原服务。备份目录在 `/root/xray-backups/`，权限 700。

自动回退不能保证在异常宿主环境下一定成功，失败后应查看备份目录和 `journalctl -u xray`。

## 验收清单

1. `systemctl status xray` 和 `systemctl status xray-sub` 均为 active。
2. `ss -lntp` 能看到代理内部端口和订阅内部端口在监听。
3. `xray-admin --sub` 输出的订阅地址能在本机或另一台设备打开，返回 YAML。
4. 用手机流量或另一台电脑导入订阅，访问测试地址，确认出口 IP 是这台 VPS。
5. 验证本地直连的站点（NAS、内网、国内服务）仍然直连；这些私有规则应放在客户端覆写，不放在 VPS 订阅。
6. 重启服务、重启实例后各验证一次。

未完成这些验证前，不要认为已经长期稳定。

## 已知限制

- 仅支持 Debian amd64 + systemd。
- 128 MB 内存是低配下限，长期高并发需要观察；`GOMEMLIMIT` 是缓解措施，不是已证明的故障根因修复。
- 配置能降低被动识别概率，但不能保证 IP 不被封。
- 订阅是 HTTP，令牌只控制访问，不加密传输。
- 流量额度是手动快照，不自动统计、限流或按月重置。
- 私有设备规则只在客户端，VPS 不保存、不合并、不导出。
- 日志写入 journald，已设速率限制，但仍需定期检查磁盘。
